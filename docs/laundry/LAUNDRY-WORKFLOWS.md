# Laundry workflows

## Configured now

A template stores a stage list:

- Wash and fold: received, tagged, sorting, washing, drying, folding, quality check, packing, ready for collection.
- Dry cleaning: received, tagged, sorting, pre-treatment, dry cleaning, finishing, quality check, packing, ready for collection.
- Press only: received, tagged, ironing, quality check, packing, ready for collection.

These names are data. Nothing in this phase creates an order or moves a garment between stages. A service can name one of these workflow codes.

Operating modes are a list on laundry settings. A business can enable more than one. Enabling a mode does not turn on pickup, production, or commercial billing by itself.

## Not implemented

Order intake, tagging, scanning, production batches, machine assignment, quality results, rework, claims, collection release, and delivery stops. An order cannot be marked ready because there is no order.
