# O8.2 release key configuration

Status: **AWAITING APPROVAL** for a production public key. The build contract is implemented.

`build.rs` compiles three public values into the binary when they are present in the environment:

- `POS_ENTITLEMENT_KEY_ID`
- `POS_ENTITLEMENT_PUBLIC_KEY`
- `POS_ENTITLEMENT_PUBLIC_KEYS` as `key-id:base64,key-id:base64`

`production_trusted_keys` reads the plural list and adds the singular pair when that id is not already present. A bad list entry is skipped. An empty list fails closed at verification. The values are not printed.

A release build with `POS_ENV=production` fails at compile time if all three are empty. Debug and acceptance builds still compile. No key was generated.

`o2-test-1` is added only under `cfg(test)`. `the_test_signing_key_is_not_a_release_key` passed in the 53 desktop tests.

Production release acceptance stays **AWAITING APPROVAL** until an authorized public key is supplied from outside this repo. The private seed stays off the register.
