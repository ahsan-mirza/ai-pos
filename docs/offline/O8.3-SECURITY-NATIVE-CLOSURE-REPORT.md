## 2. Staff provisioning

There is no refresh-token endpoint. An online PIN unlock stores the access token in memory. A local unlock does not. `unlock_cashier` and `pin_login` retry delivery only when that token is present. Delivery still requires Store Manager or Super Admin plus `users:create`.

| Situation | Outbox | Local cashier |
| --- | --- | --- |
| No access token | `awaiting_authentication` | Stays active and `pending` |
| HTTP 401 | Same event stays `awaiting_authentication`. That token is not sent again | Stays active and `pending` |
| Next online unlock with a new token | The original event id is sent again | Unchanged until the server accepts it |
| Network error or HTTP 5xx | `retryable`, same event id | Unchanged |
| HTTP 403 | `permission_denied`. It is not selected again | Stays active and `pending` |
| HTTP 422, or 409 that is not a conflict | `rejected` | A rejected create is deactivated, as before |
| HTTP 409 `provisioning_conflict` | `provisioning_conflict` | The local row is not rewritten |
| `accepted` or `duplicate` | `accepted` | Other terminals import only from the device staff feed |

The PIN and the verifier are not written to the command error text. Ordinary user responses still omit the verifier.

## 3. Online and offline allocation

The existing sale service is contract A.

An offline session calls `allocation::commit_queued`. The SQLite grant and the queue row commit together. The payload carries the allocation id, product, quantity, and the sequence assigned by that commit.

An online session calls `Db::enqueue` and does not draw the local grant. The server, when `allocations` is empty, sells `inventory_levels.available`, which is on-hand minus reserved. It does not reduce `quantity_consumed` on either terminal. A later offline sale still draws that terminal's own remaining grant. A sale from terminal A that names terminal B's allocation is rejected. A duplicate does not add a second `SALE_OUT`. A changed payload under the same key stays `idempotency_conflict` and does not release the reservation.

An online checkout was not changed to spend the terminal's own reservation. Doing that as well as the local grant would decrement the same units twice.
