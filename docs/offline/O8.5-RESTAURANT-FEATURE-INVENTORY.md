Status of the product as inspected. A row is not offline-enabled unless the local write and the sync path both exist.

## Conflict rules that already exist

- Menu, prices, tax, and permissions stay server-authored. The register caches them.
- Open-order lines merge by client id. A repeated line id does not insert a second row.
- A second open dine-in for the same table is rejected. The local order is not deleted and the bills are not merged.
- Sale idempotency is unchanged. A sale older than `sale_max_age_days` (30) is refused and needs a manual entry.
- Stock still uses the existing inventory and allocation paths. Restaurant orders do not add a second ledger.

## Not in this product

Pickup as its own order type, time-based menu availability, course firing as a separate entity, and a restaurant-only outbox are not separate implementations. Do not add them as if they were already there.
